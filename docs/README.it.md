Lunote è un **workspace di knowledge management nativo IA** — una base di conoscenza personale dove le idee si collegano, crescono e l'IA può comprenderle davvero. Apri una cartella `.md` e costruisci un sistema, non solo una pila di note.

| | |
|---|---|
| **Platforms** | macOS, Windows, Linux |
| **UI languages** | English, 简体中文, 繁體中文, 日本語, 한국어, Deutsch, Français, Español, Русский, Português (Brasil), Italiano |
| **Export** | PDF, Word (DOCX), HTML, PNG · print |
| **Security** | Optional workspace encryption (AES-256-GCM) · passwords never saved on disk |

Note di rilascio in [CHANGELOG.md](../CHANGELOG.md). **v1.0.4**: aprire un workspace non resta più bloccato sulla sovrapposizione di caricamento; l'editor visivo resta su TipTap 3.23.1 (3.30/3.31 rompeva la modifica).

<a id="why-lunote"></a>

## Perché Lunote

La maggior parte delle app per note aiuta a **catturare** informazioni. Poche aiutano a **costruire conoscenza**.

- **Le note ordinarie diventano silos** — le idee si accumulano in cartelle, ma le relazioni restano invisibili. Ricordi di aver scritto qualcosa, ma non come si collega al resto.
- **Le connessioni fanno crescere la conoscenza** — wiki link, backlink e note correlate trasformano pagine isolate in una rete navigabile.
- **L'IA dovrebbe capire tutta la knowledge base** — non solo il documento aperto. Con contesto del workspace, note collegate e ricerca, l'IA può sintetizzare, suggerire link e rivelare lacune.
- **Le note possono restare cifrate a riposo** — crittografia workspace AES-256-GCM opzionale protegge Markdown su disco; password per sessione; mai salvata su disco.

Lunote è pensato per questo: una **knowledge base personale local-first** con **crittografia workspace** opzionale, dove pensiero connesso e comprensione IA lavorano insieme — senza lock-in cloud, account o labirinto di plugin.

<a id="key-features"></a>

## Funzioni principali

<!-- readme-body-start -->

### Knowledge base con IA

IA che capisce e lavora con le tue note — non una finestra chat a parte.

- **Conversazioni workspace-aware** — contesto dalla nota corrente, selezione, menzioni `@`, vicini collegati e ricerca workspace
- **Ricerca IA** — estratti rilevanti in tutto il vault quando chiedi
- **Riassunti e sintesi** — condensare note, selezioni o temi in punti chiave
- **Assistenza alla scrittura** — continuare, riscrivere, tradurre e strutturare in Markdown Lunote
- **Sintesi della conoscenza** — analisi tra note, panoramiche workspace e insight per tema

Porta la tua chiave API in **Preferenze → IA** (OpenAI, Anthropic, Google, DeepSeek, OpenRouter, Ollama e altri).

### Conoscenza connessa

Costruisci relazioni tra idee — fondamento di un sistema di conoscenza vivente.

- **Wiki link** — `[[collega note]]` mentre scrivi; rinominare aggiorna i link nel vault
- **Backlink** — vedere cosa punta alla nota che stai leggendo
- **Note correlate** — seguire i fili senza perdere il contesto
- **Collegamenti bidirezionali** — connessioni automatiche in entrambe le direzioni

### Scoperta della conoscenza

Trova idee correlate, pattern e connessioni nascoste nel workspace.

- **Suggerimenti di link** — l'IA propone `[[wiki link]]` in base alle note esistenti
- **Scoperta di relazioni** — come i temi si raggruppano e si collegano
- **Esplorazione tematica** — cosa sai, cosa manca e cosa scrivere dopo
- **Collegamenti mancanti** — lacune, orfane e idee poco collegate

### Visualizzazione del grafo della conoscenza

Il grafo è una **vista della rete di conoscenza** — come le idee si collegano intorno al tuo focus attuale.

- **Sottografo locale** centrato sulla nota aperta — profondità e filtri
- **Navigare per connessione** — saltare tra note collegate dal grafo
- **Vedere la conoscenza evolversi** — cluster che si formano collegando più idee

> Vista predefinita: **sottografo locale** intorno alla nota attiva. **Globale** o schermo intero per un grafo di collegamenti del workspace. Limiti: **esteso** (predefinito) 400 nodi / 700 archi, **standard** 250 / 400, **compatto** 120 / 200 — non un grafo vault illimitato come Obsidian.

### Markdown nativo

Note future-proof in un formato aperto e portatile.

- **Markdown first** — modalità visuale o sorgente; focus mode per profondità
- **Formato aperto** — file `.md` su disco; nessun database proprietario
- **Note portatili** — la stessa cartella in Obsidian, Typora o qualsiasi tool Markdown
- **Contenuti ricchi** — blocchi di codice, tabelle, matematica, Mermaid, callout; export PDF, Word, HTML, PNG

### Crittografia workspace

Proteggi note sensibili a riposo — integrata, senza plugin.

- **AES-256-GCM** — corpi note Markdown cifrati su disco
- **Password per sessione** — sblocco all'apertura del workspace; mai salvata su disco
- **Opzionale per workspace** — abilita in **Preferenze → Sicurezza**
- **Immagini opzionali** — gli allegati restano in chiaro di default; **Cifra immagini** cifra i formati comuni (PNG, JPEG, WebP, GIF, HEIC, SVG, ecc.)
- **Blocco automatico** — dopo inattività (5 minuti predefiniti) salva e blocca un workspace cifrato sbloccato; il lavoro ancora sporco salta il blocco

### Local First

La tua conoscenza resta sotto il tuo controllo.

- **Possiedi i dati** — note sulla tua macchina in una cartella workspace
- **Basato su workspace** — apri qualsiasi vault; sincronizza con Git, Syncthing o iCloud alle tue condizioni
- **Privacy** — offline-first, nessun account; IA solo secondo la tua configurazione
- **Crittografia quando serve** — vedi **Crittografia workspace** sopra; password mai salvate su disco
- **Leggero** — strumenti di conoscenza integrati; [pacchetti temi](https://github.com/lunote-code/lunote-theme) opzionali

### Essenziali di produttività

- Tab, outline, Command Palette (`Cmd+Shift+P`), snapshot per nota
- Ricerca globale (`Cmd+Shift+F` / `Ctrl+Shift+F`), menu `/`
- Temi chiaro/scuro e pacchetti opzionali in **Preferenze → Plugin**

<a id="getting-started"></a>

## Per iniziare

1. **[Download](#download)** Lunote per macOS, Windows o Linux.
2. **Apri il workspace** — vault Obsidian, export Notion, cartella Typora o qualsiasi cartella `.md`. Nessuna importazione.
3. **Crea connessioni** — digita `[[` per collegare; controlla backlink e grafo intorno alla nota corrente.
4. **Abilita l'IA** — aggiungi la chiave API in **Preferenze → IA**, poi interroga nota o workspace.
5. **Scopri e cresci** — suggerimenti link IA, panoramiche workspace e ricerca per pattern e lacune.
6. **Opzionale: crittografare il workspace** — in **Preferenze → Sicurezza**, abilita la crittografia per proteggere le note Markdown a riposo. Inserisci la password all'apertura. Attiva **Cifra immagini** e il blocco automatico se serve.

> **Cambi strumento?** I file non si spostano. Qualsiasi app Markdown legge la stessa cartella.

<a id="compare"></a>

## Lunote vs Notion vs Obsidian

| | Notion | Obsidian | Lunote |
|---|---|---|---|
| **I tuoi dati** | Account cloud | File `.md` locali | File `.md` locali |
| **Modello di conoscenza** | Pagine in un workspace | Vault + plugin | Workspace connesso, integrato |
| **IA** | IA cloud sui loro dati | Dipende dai plugin | IA workspace-aware (tua chiave API) |
| **Wiki link e grafo** | Base | Grafo vault (spesso plugin) | **Sottografo locale** + scoperta, integrato |
| **Prima nota** | Registrarsi e scrivere | Configurare plugin (opzionale) | Apri cartella → collega idee |
| **Crittografia workspace** | No | Plugin / OS | **Integrata** (AES-256-GCM, opzionale) |
| **Offline e privacy** | Parziale | Completamente offline | Completamente offline, senza account |

## Casi d'uso

- **Knowledge base personale** — secondo cervello con wiki link, backlink e sintesi IA
- **Ricerca e apprendimento** — collega letture, riassunti e insight tra argomenti
- **Documentazione sviluppatori** — ADR, runbook e snippet con blocchi di codice ed export PDF
- **Lasciare Notion o Obsidian** — stesse cartelle Markdown, meno attrito, nessun upload
- **Note sensibili e diari** — crittografia workspace opzionale protegge Markdown a riposo
- **Documenti di team asincroni** — condividi workspace via Git; tutti mantengono file `.md` plain

<a id="faq"></a>

## FAQ

**Serve un account o internet?**  
No. Lunote è offline-first. Le note restano locali finché non sincronizzi la cartella. L'IA richiede la tua chiave API e rete all'uso.

**Lunote è un'app note IA o un editor Markdown?**  
Lunote è una **knowledge base personale** — Markdown archivia le note, l'IA rende il workspace comprensibile e scopribile. L'editor serve il sistema di conoscenza.

**Posso aprire il mio vault Obsidian?**  
Sì. Punta Lunote alla stessa cartella. Nessuna migrazione.

**Sostituisce completamente Obsidian o Notion?**  
Non sempre. Lunote si concentra su conoscenza connessa, IA workspace-aware e workflow desktop local-first. Abbinalo a mobile o plugin specializzati se serve.

**Grafo dell'intero vault come Obsidian Graph view?**  
Parzialmente. Lunote mostra di default un **sottografo locale** centrato sulla nota aperta. Puoi passare a **Globale** o schermo intero — note collegate del workspace, con limiti (predefinito **esteso**: 400 nodi / 700 archi; **standard**: 250 / 400; **compatto**: 120 / 200). Non è un grafo vault illimitato come Obsidian.

**Come usa l'IA le mie note?**  
Il contesto include nota corrente, selezione, menzioni `@`, vicini collegati e snippet di ricerca — solo ciò che invii. Configura il provider in **Preferenze → IA**.

**Posso crittografare il workspace?**  
Sì. In **Preferenze → Sicurezza** puoi abilitare la **crittografia del workspace**. Le note Markdown sono salvate cifrate; password all'apertura. Le immagini restano in chiaro finché non attivi **Cifra immagini**. Il **blocco automatico** può bloccare una sessione sbloccata dopo inattività. Le password restano solo in memoria — se la perdi, le note cifrate non sono recuperabili.

**Ci sono plugin?**  
Solo per i temi — pack opzionali in **Preferenze → Plugin** da [lunote-theme](https://github.com/lunote-code/lunote-theme). Wiki link, grafo, IA ed export senza installazione.

**Feedback?**  
[Apri un issue](https://github.com/lunote-code/lunote/issues) o [avvia una discussion](https://github.com/lunote-code/lunote/discussions).
